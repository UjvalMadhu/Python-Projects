# Project Name: Advanced Algorithmic Thinking with Python
This folder contains various Python programs that were created as part of the online course Advanced Algorithmic Thinking with Python
All code is my own but were inspired from the examples provided from the course.

### Acknowledgement: Robin Andrews, Compucademy, Foundations of Algorithmic Thinking with Python

### Project Index:

| Sl No. | Project| Description|
|:-------|:-------|:-----------|
| 1 | Two_Sum | This is a simple brute force program that aims at finding indices of elements in a list add up to a required sum. |
| 2 | Numbers Sort Game | This is an interactive game that makes uses of Threading that asks the user to sort a list in given time |
